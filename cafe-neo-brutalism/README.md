# KERN — Coffee & Bakery (Neo-Brutalist edition)

The same one-page café site as `cafe/`, restyled in neo-brutalism:
thick black outlines, hard offset shadows, flat loud colour (yellow, pink, mint, blue, orange),
chunky press-down buttons, hatched progress bars and sticker-style labels.

## Run locally
    cd cafe-neo-brutalism
    python3 -m http.server 8081
Then open http://localhost:8081

## Notes
- Markup and `script.js` are shared in behaviour with the Swiss version (live Zürich open/closed status, menu tabs, count-up stats, reveals, form validation).
- Fonts: Archivo Black, Space Grotesk, Space Mono (Google Fonts) with Arial/Helvetica fallbacks.
- All café details are placeholders.
