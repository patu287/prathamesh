Installing

  1. Tap the button. The file lands in Downloads.
  2. Open it, and let Android install from that app when it asks.
  3. Play Protect will call it unsafe because it is not from the Play Store — choose Install anyway.
  4. Grant the microphone when asked, or recording stays silent.
