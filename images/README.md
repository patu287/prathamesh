# 📸 Little Owl Cafe — Image Upload Guide

Upload your cafe photos to the corresponding folders below. The website will automatically pick them up!

## Folder Structure

```
images/
├── hero/
│   └── hero.jpg          ← Main hero banner (cafe exterior or best interior shot)
│
├── about/
│   ├── about-1.jpg       ← Cafe interior / ambiance (tall portrait orientation preferred)
│   └── about-2.jpg       ← Coffee art or food close-up (square orientation)
│
├── gallery/
│   ├── gallery-1.jpg     ← Large feature image (cafe interior, best shot)
│   ├── gallery-2.jpg     ← Latte art / coffee close-up
│   ├── gallery-3.jpg     ← Signature dish / food plating
│   ├── gallery-4.jpg     ← Evening ambiance / lighting
│   ├── gallery-5.jpg     ← Food spread / table setting (wide/landscape)
│   └── gallery-6.jpg     ← Desserts / pastries
│
├── menu/                 ← (Optional) Menu item photos if you want to add them later
│
└── logo/                 ← (Optional) Cafe logo files
```

## Tips for Best Results

- **Hero image**: Use a high-quality wide/landscape photo (1920x1080 or larger)
- **About images**: Portrait (4:5) for about-1, Square (1:1) for about-2
- **Gallery images**: Minimum 800x800px, JPG or PNG format
- **File sizes**: Keep under 500KB each for fast loading (use TinyPNG to compress)
- **Naming**: Keep the exact filenames listed above — the website references them directly

## How to Upload

1. Go to the repository on GitHub
2. Navigate to the `images/` folder and the subfolder you want
3. Click "Add file" → "Upload files"
4. Drag your photos in with the correct filenames
5. Commit the changes

The website will auto-refresh with your images! 🦉
