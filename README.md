# 🦉 Little Owl Cafe — Premium Website

A premium, modern website for **Little Owl Cafe**, Nagpur's neighbourhood boutique cafe.

## ✨ Features

- **Premium Design** — Elegant typography, warm color palette, smooth animations
- **Fully Responsive** — Looks great on mobile, tablet, and desktop
- **Interactive Menu** — Filterable menu categories with smooth transitions
- **Photo Gallery** — Grid gallery with lightbox viewer
- **Customer Reviews** — Real reviews from Zomato, Google & District
- **Google Maps** — Embedded map with directions
- **Smooth Animations** — Scroll reveals, parallax effects, counters
- **SEO Optimized** — Proper meta tags and semantic HTML
- **No Dependencies** — Pure HTML, CSS & JavaScript (Lucide icons via CDN)

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## 📸 Adding Photos

See [images/README.md](./images/README.md) for the complete photo upload guide.

The website uses placeholder divs where your photos should go. Simply upload your images to the `images/` folder with the correct filenames, and they'll appear automatically.

## 📁 Project Structure

```
├── index.html          # Main HTML
├── style.css           # Premium stylesheet
├── app.js              # Interactions & animations
├── images/             # Upload your photos here
│   ├── hero/           # Hero banner image
│   ├── about/          # About section images
│   ├── gallery/        # Gallery photos
│   ├── menu/           # Menu item photos
│   └── logo/           # Logo files
├── package.json        # Vite dev server config
└── vite.config.js      # Vite configuration
```
