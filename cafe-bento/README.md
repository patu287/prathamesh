# KERN — Coffee & Bakery (Bento Grid edition)

The same one-page café site, rebuilt as a bento grid: modular rounded tiles of mixed sizes
on a warm canvas, soft layered shadows, and a café palette (matcha, butter, terracotta, sky, espresso).

## Run locally
    cd cafe-bento
    python3 -m http.server 8082
Then open http://localhost:8082

## Notes
- Markup and `script.js` match the other editions (live Zürich open/closed status, menu tabs, count-up stats, reveals, form validation).
- Fonts: Plus Jakarta Sans and DM Mono (Google Fonts) with system fallbacks.
- All café details are placeholders.
